## 1. Implementação do Compilador CLI (`cmd/liafc`)
- **Implementação do ponto de entrada:** Criado `cmd/liafc/main.go` unindo Lexer, Parser, AST, Checker, Diagnósticos e Codegen.
- **Comandos suportados:**
  - `liafc check <arquivo.liaf> [--json]`: Valida sintaxe e tipos com emissão de relatório JSON para agentes de IA.
  - `liafc build <arquivo.liaf> [-o saida]`: Compila binário executável nativo e estático com suporte total a cross-compilação (`GOOS=linux GOARCH=amd64`).
  - `liafc emit <arquivo.liaf>`: Emite código Go transpilado para inspeção.
  - `liafc run <arquivo.liaf>`: Executa diretamente em memória.
- **Correção de `.gitignore`:** Ajustada regra para ignorar apenas binários na raiz (`/liafc`), permitindo o versionamento do pacote `cmd/liafc`.

## 4. Componentização e Layouts em Memória RAM
- **Engine de Templates:**
  - Implementado suporte a layout base via `<!-- layout "base.html" -->` com slot `<!-- content -->`.
  - Suporte a inclusão modular via `<!-- include "arquivo.html" -->`.
  - Resolução recursiva executada uma única vez no boot em memória RAM (zero I/O de disco em runtime).
- **URLs Limpas:**
  - Mapeamento automático de rotas sem extensão (ex: `/sobre` serve `/sobre.html`, `/servicos` serve `/servicos.html`).
- **Arquitetura Modular Criada:**
  - Layout: `public/base.html`
  - Parciais: `public/menu.html`, `public/footer.html`
  - Páginas: `public/index.html`, `public/sobre.html`, `public/servicos.html`

## 5. Versionamento Automático de Assets (Zero Ctrl + F5)
- **Asset Fingerprinting:**
  - O motor inspeciona tags `<link>` e `<script>` no HTML e injeta automaticamente hashes SHA-1 dos arquivos correspondentes (`?v=<hash>`).
- **Políticas de Cache HTTP Dinâmicas:**
  - HTML entregue com `Cache-Control: no-cache, no-store, must-revalidate` (sempre atualizado).
  - Assets com hash versionado entregues com `Cache-Control: public, max-age=31536000, immutable`.
- **Resultado:** A cada deploy ou alteração de arquivo, o navegador puxa as alterações imediatamente sem necessidade de limpeza manual de cache ou atalhos de teclado.

---

## 6. VFS (Virtual File System) Sandbox e Hot-Reload
- **Jail e Isolamento de Segurança:**
  - A pasta `./public` opera como uma raiz virtual `/` estrita em memória.
  - Bloqueio nativo contra tentativas de *Path Traversal* (`..`).
- **Resolução de Caminhos Relativos:**
  - Suporte a caminhos relativos (`./`, `../`) e fallback automático para assets compartilhados na raiz.
- **Suporte Universal a Formatos:**
  - Detecção nativa e robusta de MIME types para HTML, CSS, JS, JSON, SVG, PNG, JPG, WebP, AVIF, WASM e fontes.
  - Minificação automática estendida para arquivos `.json` via `json.Compact`.
- **Hot-Reload Atômico:**
  - Estrutura com `sync/atomic.Pointer[AssetCache]`.
  - Endpoint `POST /_liaf/reload` para recarga completa de arquivos em RAM em apenas **~3 milissegundos**, sem reiniciar o binário e sem derrubar conexões ativas.

## 8. Evolução SSG: Superando o Hugo em RAM e Velocidade
- **Parser de Markdown & Frontmatter Nativo (`pkg/markdown`):**
  - Parser Go ultrarrápido e sem dependências externas pesadas.
  - Suporte a metadados Frontmatter YAML/JSON delimitados por `---`.
  - Conversão transparente de Markdown para HTML montado dentro de slots `<!-- content -->` de layouts (`base.html`).
- **Coleções & Loops de Template:**
  - Indexação automática de dados estruturados em `public/data/*.json`.
  - Alimentação automática da coleção `posts` a partir de todos os arquivos `.md` ordenados por data decrescente.
  - Sintaxe declarativa `<!-- for item in colecao --> ... <!-- endfor -->` com interpolação `{{ item.campo }}` e `{{ post.title }}`.

  - Implementado empacotamento completo de assets via `embed.FS`.
  - Suporte tanto a diretório em disco quanto a VFS embutido no mesmo executável.
  - Permite deploy de arquivo único autônomo sem necessidade de transferir a pasta `public/` via SCP.
